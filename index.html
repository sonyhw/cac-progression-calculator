    How to use

    1. Enter the baseline scan: total Agatston score (sum of LM, LAD, LCx and RCA) and the exam date.
    2. Enter the follow-up scan the same way. Use scans done with the same protocol (120 kVp, 2.5–3 mm slices), ideally on the same scanner.
    3. Select statin status for the period between the two scans. This changes the interpretation, not the arithmetic.
    4. Read the verdict. The coloured box gives the primary result (MESA algorithm, chosen by baseline score). The table shows every criterion so you can see where they agree.
    5. Copy the report sentence into your CAC report or the registry workbook, then add the vessel modifier for CAC-DRS.

    Rules used: baseline 0 → any CAC at follow-up; baseline 1–99 → ≥ 10 AU/yr; baseline ≥ 100 → ≥ 10%/yr.3 Rapid progression is ≥ 300 AU/yr.6 Intervals are calculated from the dates in days ÷ 365.25. This is a decision aid; clinical judgement and the full risk profile still decide treatment.
