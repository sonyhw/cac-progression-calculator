How to use this form
  1. Set the centre code (left panel) once per computer. Record IDs are generated from it, for example RSUI-0001.
  2. Enter one patient per record. Fields marked * are required to save. Never type names, MRN or NIK; keep that link in your centre's own log.
  3. Save with the bottom bar. A record with only the baseline scan is saved as Baseline only; open it again after the follow-up scan and complete it.
  4. Derived results (BMI, eGFR, statin intensity, CAC totals, progression criteria, CAC-DRS, quality flags) are calculated automatically and exported.
  5. Export CSV at least weekly and after each session. The file is your backup and the copy you send to the coordinating centre. Records live only in this browser; clearing browser data deletes them.
  6. Import CSV restores a backup or moves records to another computer. Records with the same Record ID are replaced by the imported version.
  7. Central registry link (optional). If the coordinating centre gave you a web-app link and a centre key, enter them under Central registry link and press Test connection. Each saved record is then sent to the central Google Sheet automatically; Submit unsent resends any that failed (for example while offline).
  8. Without the link, send the CSV to the coordinating centre by the agreed secure route. The coordinator pastes all centres' CSVs into the analysis workbook.
